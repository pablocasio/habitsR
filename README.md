# AgentSync

Agente virtual inteligente de hábitos saludables — proyecto del curso de Inteligencia Artificial (UNHEVAL, 2026-II).

## Estructura

- `frontend/` — aplicación React (Vite + Tailwind)
- `backend/` — microservicio FastAPI con tool-calling (Claude + LangChain)
- `docs/` — informes académicos y diagramas de arquitectura

## Cómo correr el proyecto

Ver el README dentro de cada carpeta (`frontend/README.md`, `backend/README.md`) para instrucciones específicas de cada lado.
